# tools/plots

Scripts for generating all benchmark figures from `pipeline_results.jsonl`.

## Quickstart

Regenerate every plot from the project root:

```bash
python -m tools.plots.main
```

Pass a custom results file:

```bash
python -m tools.plots.main --input path/to/pipeline_results.jsonl
```

Individual scripts can also be run as modules:

```bash
python -m tools.plots.testpassrate.controller.model_pass_rate
python -m tools.plots.coverage.model_coverage [--ref-file FILE]
```

## Metrics

| Directory                  | Metric                        | Eval type             |
| -------------------------- | ----------------------------- | --------------------- |
| `testpassrate/controller/` | Test pass rate                | Controller generation |
| `testpassrate/test/`       | Test pass rate                | Test generation       |
| `coverage/`                | Statement & branch coverage   | Test generation       |
| `complexity/`              | Average cyclomatic complexity | Controller generation |
| `size/loc/`                | Lines of code                 | Controller generation |
| `size/coc/`                | Characters of code            | Controller generation |

Each metric has three breakdowns: by **prompt configuration** (`config_*`), by **LLM** (`model_*`), and by **modeling tool** (`tool_*`).

## Reference baselines

`coverage/`, `complexity/`, and `size/` support an optional `--ref-file` argument that draws a dashed human-reference line on the plot. The reference files are generated by the `compute_reference.py` scripts in each subdirectory, which read directly from `data/`:

```bash
python -m tools.plots.coverage.compute_reference
python -m tools.plots.complexity.compute_reference
python -m tools.plots.size.compute_reference
```

This only needs to be re-run when the ground-truth controllers in `data/` change. The generated `reference_*.jsonl` files are stored alongside the plotting scripts in each subdirectory.

## Common options

All plotting scripts accept:

| Flag              | Default                      | Description                                                |
| ----------------- | ---------------------------- | ---------------------------------------------------------- |
| `--input FILE`    | `pipeline_results.jsonl`     | Source results file                                        |
| `--output FILE`   | `<script_dir>/<name>.png`    | Output PNG path                                            |
| `--ref-file FILE` | `<subdir>/reference_*.jsonl` | Human-reference baseline (coverage, complexity, size only) |
