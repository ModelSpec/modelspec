Recently, a new social network site, Facepage, was founded. When new users want to join Facepage, they first need to provide their personal information, namely a user ID, a name, an email address, and a date of birth. The user ID must not be empty. The name must not be empty. The email address must contain exactly one "@" character, must contain at least one "." after the "@" character, and must not end with a "." character. The date of birth must not be in the future. A user ID must be unique; if a user with the same ID already exists, the system will reject the registration with the error "A user with the ID already exists."

Once registered, a user creates an account. An account is uniquely identified by an account number that is automatically generated by the system and is guaranteed to be unique across all accounts. Each user may hold exactly one account, regardless of type. If a user already has an account, whether personal or business, the system will reject any attempt to create an additional account for that user with the error "A user with the ID already has an account."

The user must choose between two account types: a business account or a personal account. A business account is specifically designed to support companies in their marketing campaigns; when a user opens a business account, he or she must specify the name of the company. When a user opts for a personal account, he or she can keep in touch with other Facepage users.

Each account can create and administer several pages. Each page must be administrated by exactly one account. For each page, the page name and the number of visits are recorded, and the number of visits on a newly created page starts at zero. Within a single account, no two pages may share the same name; if an account attempts to create a page with a name already used by one of its own pages, the system will reject the request with the error "A page with the name already exists." A page name may not be empty; attempting to create a page with an empty name produces the error "The page name cannot be empty." Different accounts may, however, have pages that share the same name without conflict.

Only personal accounts can create personal pages. If a business account attempts to create a personal page, the system will reject the request with the error "Only personal accounts can create personal pages."

Users with a business account can create a special type of page called an advertisement page. Only business accounts can create advertisement pages; if a personal account attempts to create an advertisement page, the system will reject the request with the error "Only business accounts can create advertisement pages." An advertisement page records several metrics: the bounce rate, the click-through rate, and the conversion rate, each of which starts at zero when the page is first created. The bounce rate is the percentage of visitors on the page that leave immediately. The click-through rate is the percentage of visitors that click on a certain banner on the page. The conversion rate is the percentage of visitors that accomplish the intended goal, such as a purchase or a transaction.

Only personal accounts can send or receive friend requests. If a business account attempts to send a friend request, the system will reject the request with the error "Only personal accounts can send friend requests." If a business account is specified as the receiver of a friend request, the system will reject the request with the error "Only personal accounts can receive friend requests." A friend request must have both a valid sender and a valid receiver; if no receiver is specified the system raises the error "Cannot create a friend request without a receiver," and if no sender is specified the system raises the error "Cannot create a friend request without a sender." An account cannot send a friend request to itself; attempting to do so produces the error "Cannot send a friend request to itself."

Personal accounts can be granted privileges on pages belonging to other personal accounts. Privileges may only be granted on personal pages; attempting to grant a privilege on an advertisement page produces the error "Cannot grant privilege on an advertisement page." Privileges may only be granted to personal accounts; attempting to grant a privilege to a business account produces the error "Cannot grant privilege to a business account." The privilege type must not be empty; if it is, the system raises the error "The type of privilege cannot be empty." The target page must not be empty; if it is, the system raises the error "Page cannot be empty." The owner of the page must not be empty; if it is, the system raises the error "Owner of the page cannot be empty." The target user to whom the privilege is granted must not be empty; if it is, the system raises the error "Target user cannot be empty." Both the page owner and the target user must be existing users; if either does not exist, the system raises the error "User "<userId>" does not exist." The specified page must exist for the given owner; if it does not, the system raises the error "Page "<pageName>" does not exist for user "<userId>"." Finally, a privilege cannot be granted to the owner of the page itself; attempting to do so produces the error "Cannot grant privilege to the owner of the page."
