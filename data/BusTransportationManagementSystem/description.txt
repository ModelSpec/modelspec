A city is using the Bus Transportation Management System (BTMS) to simplify the day-to-day activities related to the city's public bus system.

The BTMS keeps track of a driver's name. The name of a driver cannot be empty. A bus route is identified by a unique number that is determined by city staff. The number of a route must be greater than zero and cannot be greater than 9999. If city staff attempts to create a route with a number that is zero or negative, the system rejects the request with the message "The number of a route must be greater than zero." If the number exceeds 9999, the system rejects the request with the message "The number of a route cannot be greater than 9999." If city staff attempts to create a route with a number that already exists, the system rejects the request with the message "A route with this number already exists. Please use a different number."

For up to a year in advance, city staff assigns buses to routes. A bus must exist in the system in order to be assigned to a route, otherwise the assignment is rejected with the message "A bus must be specified for the assignment." Similarly, the route must exist in the system, otherwise the assignment is rejected with the message "A route must be specified for the assignment." The date of an assignment must be within a year from today; if the date falls outside this range, the assignment is rejected with the message "The date must be within a year from today."
